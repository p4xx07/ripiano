## How to verify locally

- **API:** `cd services/api && RIPIANO_DEBUG=1 .venv/bin/pytest -q`. Expect about 160 passed, 6 skipped. The skipped tests need the zbar library, absent on macOS; they pass in the Linux image. To run them there: `docker run --rm -u root -e RIPIANO_DEBUG=1 -e UV_NO_DEV=0 -e UV_PROJECT_ENVIRONMENT=/tmp/venv -v "$PWD":/work:ro --entrypoint sh ripiano-api -c "cp -r /work /tmp/src && cd /tmp/src && rm -rf .venv && uv sync --frozen --group dev -q && /tmp/venv/bin/pytest -q archive/test_barcodes.py"`.
- **Stack:** the local Compose stack is on port 18080. Start the mail test server with `docker compose -f deploy/compose.mailtest.yaml up -d`. The stack env needs these values:
  - `RIPIANO_SMTP_HOST=mailtest`, `RIPIANO_SMTP_PORT=3025`, `RIPIANO_SMTP_SECURITY=none`, and `RIPIANO_DOCUMENT_EMAIL=1`.
  - The Docker credential helper on `PATH`: `export PATH="$PATH:/Applications/Docker.app/Contents/Resources/bin"`.
- **Browser:** `RIPIANO_E2E_ORIGIN=http://localhost:18080 RIPIANO_E2E_USERNAME=… RIPIANO_E2E_PASSWORD=… RIPIANO_E2E_2FA_USERNAME=… RIPIANO_E2E_2FA_PASSWORD=… npx playwright test --workers=2`.
  - The last full runs: every journey passed except `agents.spec.ts` and `visual-review.spec.ts` (desktop and mobile). Those need the e2e account to be an instance admin (`is_superuser`); the disposable account used here is not.
  - The 2FA journey needs its own disposable non-admin account.
  - A visual-review run overwrites `qa-artifacts/65d544b`. Run `git checkout -- qa-artifacts` afterwards.
- **Not runnable here:** CI cannot be edited from this environment (`.github` is protected). To run the zbar tests in CI, add `sudo apt-get install -y ghostscript libzbar0t64` to the `api` job.
