# Judge fixes: web accessibility and language (2026-11-18)

Scope: apps/web only. No dependencies added, no Docker changes. Checks run: `npx tsc --noEmit -p .` (clean) and `npm run build` (ok). The new and updated Playwright specs parse (`playwright test --list`), but they have not been run against a rebuilt stack yet.

| # | Finding | Change | Regression |
|---|---|---|---|
| 1 (H) | The sidebar and mobile drawer could not scroll, so sign-out and Language were unreachable. The note card spilled white-on-cream below the sidebar. | `App.tsx`: the sidebar is now brand + `.sidebar-scroll` (nav, appearance, language, note) + a pinned account row. `style.css`: `.sidebar-scroll` uses `flex:1; min-height:0; overflow-y:auto; overscroll-behavior:contain`. The sidebar height is `100dvh` with a `100vh` fallback. The note now stays inside the scroll area, so the overflow is gone. | `navigation-a11y.spec.ts`: "sign-out and the language picker are reachable on every screen size" checks 1440x900, 1280x720, 390x844, 375x667 and 320x640. |
| 2 (M) | The account block was the sign-out button (name "J judge1 Admin"). | The account block is now a plain `div`. A separate `<button class="sign-out" title="Sign out">` shows the visible text "Sign out", so the existing `button[title="Sign out"]` specs still work. | The landmark test checks that no button is named after the user and that exactly one "Sign out" button exists. |
| 3 (M) | Focus was lost after "Add a sender" / "Add a type". | `DocumentPanel.tsx`: the new name inputs get `autoFocus`. After a create, focus moves to the sender or type select. After a cancel, it returns to the "Add a …" button (`focusSoon`). | The document dialog test. |
| 4 (M) | Every document dialog had the same name. | The `h2#detail-heading` now shows `current.title`. "Keep it in place." moves into the intro as a bold tagline. All 26 specs that used `getByRole("dialog", { name: "Keep it in place." })` now use `getByRole("dialog").filter({ hasText: "Keep it in place." })`. | The document dialog test checks that the dialog name and h2 equal the document title. |
| 5 (M) | The paper-copy move `<select>` had no label. | Added `aria-label={m.moveCopyTo(sticker_code)}` (EN and IT). | Not covered here; the accessibility audit covers labels. |
| 6 (M) | Three unnamed "Choose File" inputs were exposed to screen readers. | Each input gets `aria-hidden="true"` (it already had `tabIndex=-1`) plus an `aria-label` for the static audit. The visible buttons still call `.click()` on them. | The Add dialog test checks that no "Choose File" button exists, that all three inputs are aria-hidden, and that "Browse files" still opens a filechooser. |
| 7 (M) | There was no nav landmark, no current-page state, a fixed English title, and no focus move on screen change. | `<nav aria-label="Main navigation">` (IT "Navigazione principale"). The active item gets `aria-current="page"`. `document.title` is now "<screen> · Ripiano", and "Ripiano — your documents, in place" (localized) when signed out. index.html's static title is just "Ripiano". A new `goTo()` handles menu clicks and `g`+letter: it moves focus to `#main-content h1`, falling back to `#main-content`, after the screen changes. This does not happen on first load. | The landmark/title/focus test, which includes the Italian title. |
| 8 (M) | Touch targets were too small, and search results started too far down on phones. | `@media (pointer: coarse)` sets 44px minimums for `.text-action`, `summary`, `.document-title-button`, `.nav-link`, `.sign-out`, `.modal-close`, the search clear button and the search input. Row icons are 40x44. The menu and close buttons are 44x44 at ≤800px. Desktop is unchanged. `.library-searching`, set while a Library query is active, hides the eyebrow, intros and counts at ≤800px. | Menu button ≥44, close ≥44/≥40, and the phone search test (counts hidden, first row above the fold). |
| 9 (M) | Suggestion explanations were in English. | `suggestionBasis(item, text)` takes localized `suggestionLikely/Like/Shared` from `locales/DocumentPanel.ts`. | Type-checked. EN text is unchanged. |
| 10 (M) | The agent activity log showed raw tool names and outcomes. | `AgentPanel.tsx` maps the 7 MCP tools and ok/denied/error to EN and IT labels. Unknown tools fall back to the raw name with underscores replaced. | Not covered here. |
| 11 (M) | An Italian device started in English, and the option read "Italiano (preview)". | `i18n.ts`: with nothing saved, the preference is now `system` (follow the device). The option reads "Italiano". `language.spec.ts` now asserts that an it-IT device starts in Italian and that English can be chosen and is remembered. A new test checks that an en-GB device starts in English. `playwright.config.ts` pins `locale: "en-US"` so the English-label specs don't depend on the host locale. | `language.spec.ts`. |
| L5 (judge 3) | Closing a document opened with j/Enter returned focus to `<main>`. | j/k now move real focus to the row's title button. Enter also focuses it before opening, so the Modal hands focus back to the row on close. This also fixes judge 2's "j/k move only a highlight". | "closing a document opened with j and Enter returns focus to its row". |
| L10 (judge 3) | Agent revoke acted on the first click. | An inline confirm, like the trash confirm: "Revoke <name>" shows "Revoke access for “<name>”? …" with "Yes, revoke" (danger) and "Cancel". `agents.spec.ts` is updated to click through the confirm. | `agents.spec.ts`. |

Resource impact on the NAS: none. The changes are CSS and markup only; the bundle size is essentially unchanged.
