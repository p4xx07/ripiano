## Current state

The five formerly open items in `DECISIONS.md` are implemented: background job controls, sharing of tags/senders/types/saved views, API v1 body contracts, English/Italian screens and reviewed API messages, and keyboard shortcuts with an accessibility pass. They are not yet independently reviewed as a group or verified for the R4 parity gate.

Since `bbe32e3` (Unlock PDFs), this branch added a Raspberry Pi gateway example, optional semantic search, Sources for S3-compatible storage/WebDAV/NAS folders/Telegram/cloud drives, a built-in consume folder, object sharing, the API contract, and localization/accessibility work. The current tip before this handoff was `76774b3`. See `git log bbe32e3..HEAD` for exact commits. The older `docs/HANDOFF_2026-11-13.md` describes a substantially earlier state.

Ripiano uses AI through MCP clients and named agent grants. The optional local Mac classifier is separate. Semantic search is off by default; when enabled, Ripiano creates embeddings through an Ollama-compatible endpoint on another computer or the optional NAS embedder and returns passages, while the MCP client's model writes any answer. The NAS embedder was measured at about 780 MB RAM with a model loaded. It must remain optional; no new always-on NAS process or runtime dependency should be added without asking the owner.

Sources are set up in the app. The consume folder is automatically represented by a built-in source when mounted. Real provider accounts and the owner's NAS remain untested. The Library currently presents semantic hits separately as “Related by meaning”; hybrid ranking in the main results is the next product change.

## Verification commands

- API: `cd services/api && RIPIANO_DEBUG=1 .venv/bin/pytest -q`. Last reported expectation: about 242 passed, 9 skipped; the skipped barcode tests need zbar. Run afresh after changes.
- API contract: `archive/test_api_contract.py` must stay green. Fields may be added, but existing fields, types, status codes, and routes cannot be removed or changed. Regenerate only after intended compatible changes: `RIPIANO_WRITE_CONTRACT=1 RIPIANO_DEBUG=1 .venv/bin/pytest -q archive/test_api_contract.py`.
- Web: `cd apps/web && npx tsc --noEmit -p . && npm run build`.
- Browser: with a live stack, `cd apps/web && RIPIANO_E2E_ORIGIN=<stack URL> RIPIANO_E2E_USERNAME=<disposable owner> RIPIANO_E2E_PASSWORD=<password> npx playwright test`. Tests use Chrome. Upload-processing journeys need the background worker; otherwise documents remain pending. Some security journeys need an additional 2FA account. The local Compose stack has previously used port 18080.
- Android debug: `cd apps/android && ./gradlew :app:assembleDebug` with JDK 17 and Android SDK 36. A build does not replace real-phone camera and interrupted-upload tests.
