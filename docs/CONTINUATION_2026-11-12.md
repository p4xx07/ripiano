## Current state

The [parity matrix](FEATURE_PARITY.md) tracks broader Paperless capabilities still missing.
- Trash supports restore, confirmed permanent deletion, backup-locked live-file cleanup with durable retry, and per-owner automatic retention. Retention is disabled by default. The owner can choose 30–3650 days, preview the number currently eligible, and confirm a daily 03:00 Europe/Rome task. Turning it off stops future selection; already queued cleanup finishes. Existing snapshots and Synology Hyper Backup have separate retention.
- The retention, custom-field type-change, and collection-export slices passed 69 local API tests with one PostgreSQL-only concurrency case skipped, plus all three share tests on PostgreSQL; migration/system checks, a production PWA build, and 64 desktop/mobile browser journeys. - Filing suggestions (`GET /api/documents/<id>/filing-suggestions`) compare a ready document with up to 300 recent manually filed documents by the same owner, using title and early-OCR words without stopwords or words common to many examples. They suggest tags, senders, and types with the example and the shared words. They never change data, call a model, or need a migration, and the similarity value is not a calibrated confidence. The API suite passed 81 tests with one PostgreSQL-only skip. The browser suite passed except for the agents and visual-review journeys, which need an instance-admin test account. - Email intake adds IMAP mailboxes (an app password, or Gmail/Outlook OAuth when the operator configures clients) and ordered mail rules in a new Email screen. The maintenance queue polls every 5 minutes, and Check now runs a poll on demand. Attachments anywhere in the MIME tree are imported once per owner, with rule tags, sender, and type kept apart from phrase rules (origin `source`). The document shows its email origin. Mail is never deleted. Browser journeys use a local GreenMail server (`deploy/compose.mailtest.yaml`). Review findings and resolutions are in `.omo/evidence/email-intake-review.md`. Processing whole `.eml` messages remains open.
- More formats: legacy DOC/XLS/PPT (OLE signature check), OpenDocument ODT/ODS/ODP (declared mimetype; macros refused), RTF, and EML. An EML is titled by its subject and rendered to a searchable PDF from escaped text only. Mail rules can import attachments, the email itself, or both. One shared extension list now drives web upload, the watched folder, and mail attachments. Real conversion of .doc, .odt, and .eml passed in desktop and mobile journeys (`e2e/formats.spec.ts`).
- Barcodes: `archive/barcodes.py` rasterizes up to 100 pages with Ghostscript and decodes with zxing-cpp. Separator pages split a PDF into parts (`split_parent`); the source keeps `is_split_source` and is excluded from Library, MCP search, and filing suggestions. ASN is unique per owner, editable in the document dialog, and searchable with `asn:`. TAG: codes add existing tags with origin `source`. Fixtures `barcode-batch-*.pdf` drive `e2e/barcodes.spec.ts`.
- Versions and page tools: `Document.original_*` always describe the current version, and `DocumentVersion` keeps older files. `archive/versions.py` implements adding, restoring, page editing, splitting into new documents, and merging. The endpoints are in `version_views.py`. Page previews are Ghostscript PNGs cached under `previews/`. Purge jobs carry `version_files`, and exports include `versions/`. The UI is `PagesPanel.tsx` in the document dialog plus a Library bulk "Merge into one PDF".
